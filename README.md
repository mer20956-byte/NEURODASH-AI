# NEURODASH AI
Experimental Geometry Dash Geode mod for Android ARM64 / Geometry Dash 2.2081.

## Status
This is a v0.1.0 interface prototype. It adds an `AUTO PLAY` menu button and displays a prototype status message. Autonomous gameplay is not implemented yet.

## Build
Push this project to a GitHub repository. Open Actions and run **Build NEURODASH AI (Android ARM64)**, or push to `main`. Download the `NEURODASH-AI-Android64` artifact from the workflow run.

The workflow uses the `geode-sdk/build-geode-mod` action.
